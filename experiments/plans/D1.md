# D1. Magic decks: do the card embeddings, the transport edits and the diverse lists hold on fresh data?

## Question

`mtg_decks/README.md` answers three questions on Bloomburrow (BLB) Premier Draft decks from 17Lands, as exploratory results: which cards go together, how a deck should change to look like the winning decks, and how to make a list of suggestions diverse. Every number there was computed with the fit half of the drafts and, for the held-out scores, the dev quarter. This plan fixes the configuration and scores it once on data that no exploratory run has touched:

1. **Q1, a new set.** On the newest set with 17Lands game data when this was written (17Lands code FRA, Premier Draft, file dated 2026-10-17), do a card's 10 nearest neighbors in the PPMI embedding share its most-played color pair more often than color alone explains?
2. **Q2, the test quarter of BLB.** On held-out BLB test decks, does the transport score (distance to the average losing deck minus distance to the average winning deck, embedding cost) rank won games above lost games of the same color pair and skill bucket less well than the frequency-difference score, as it did on dev?

The only things looked at for FRA so far are its column names, its first three rows and its card list (`compute/mtg-probe-44787048148`).

## Why it matters

The exploratory results choose among several measures after seeing them; one (the off-color partner vote) was defined after the first was seen. A fresh set and an untouched quarter say whether the headline numbers are properties of the methods or of choices made while looking.

## Fixed configuration

Everything is as in `mtg_decks/` at the commit that merges this plan:

- vocabulary: nonbasic cards held by at least 100 fit decks (one build per draft, the one with most games); splits by `decks.split_of` (SHA-256 of the draft id: half fit, a quarter dev, a quarter test);
- embedding: PPMI over fit decks, its 32 leading eigenvectors scaled by the square roots of their eigenvalues (`study.ppmi_embedding`); K = 10 neighbors by cosine;
- transport: exact optimal transport (POT `emd`) with cost the Euclidean distance between unit vectors; targets the game-weighted average decks of fit games won and lost, per color pair;
- strata: the ten color pairs, crossed with 17Lands' `user_game_win_rate_bucket`;
- MMR: lists of 5, λ on the grid 0, 0.1, …, 1.

## Primary metrics and tests

Two primary hypotheses, Holm-corrected at 5%.

- **H1 (Q1, FRA).** Δ₁ = pair agreement at K = 10 minus `pair_within_color` chance (random neighbors among cards that include the card's color), over one-color cards. Interval: bootstrap over cards, 10,000 resamples, seed 0. H1 holds if the interval lies above 0.
- **H2 (Q2, BLB test).** Δ₂ = stratified AUC of the transport score minus that of the frequency-difference score, strata pair × skill bucket. Interval: bootstrap over drafts, 10,000 resamples, seed 0. The test is two-sided; the dev estimate was −0.0073 (−0.0094 to −0.0051).

## Secondary metrics (reported, no test)

- On FRA: pair and color agreement for skip-gram (5 seeds) and for the shuffled-deck null (5 seeds).
- On BLB test: the AUCs of every score in `score_heldout`, with and without skill strata, and the Spearman correlation of each with skill; the pairing measures (mana value gap and same card type) for transport, baseline and random pairing on 3,000 seeded decks; MMR's relevance kept and redundancy over λ.
- On BLB test decks: the two partner-color votes, with co-occurrence counted on test decks instead of fit decks.

## Minimum detectable effect

- H2: the dev bootstrap gives a standard error of about 0.0011 for Δ₂, and the test quarter has the same size (39,946 drafts against 40,125). The detectable effect at 80% power is 2.80 × 0.0011 ≈ 0.003 of AUC. An effect smaller than that is reported as a null with its interval.
- H1: on BLB, one-color cards number about 190 and the per-card pair agreement has a standard deviation near 0.2, so the detectable effect is about 2.80 × 0.2 / √190 ≈ 0.04, far below the 0.4 seen on BLB. If FRA has a different structure (three-color archetypes, for example), a null is reported with the detectable effect.

## Seeds

Bootstrap seed 0. Skip-gram seeds 1 to 5, null seeds 1 to 5, the same as on BLB; these are method seeds, not evaluation draws. The deck sample for the pairing measures uses seed 0.

## Compute and cost

CPU on GitHub Actions (`experiment.yml`, group `mtg_decks`): the BLB build took 117 seconds. Two jobs: `mtg_decks.build --set FRA` (fit and dev aggregates, used for H1 only through fit), and a test-scoring job for BLB that reads the test split, which needs a `--split test` option written after this plan is merged and before the run. Cost $0; timeout 60 minutes each, one rerun at most.

- A README section with both answers, nulls included.

## If the result is null

If H1 fails, the README says the color-pair structure seen on BLB does not carry to FRA at the detectable effect. If H2's interval covers 0, the README says the dev difference between transport and frequency difference was not confirmed, with the detectable effect.
